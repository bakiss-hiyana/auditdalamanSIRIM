Modul Fungsi Peranan

▶️ Cara Jalankan Aplikasi

Langkah 1 — Buka terminal di folder projek

cd "d:\KURSUS AI MDEC_PRIP\tennis-predictor"

Langkah 2 — Jalankan Streamlit

streamlit run sirim_audit/app_sirim.py

Langkah 3 — Buka browser

http://localhost:8501
✅ Browser akan terbuka secara automatik. Log masuk dengan mana-mana akaun di atas untuk mula menggunakan sistem.
⚠️ Jika port 8501 sudah digunakan, Streamlit akan guna port lain seperti 8502, 8503 secara automatik. Semak terminal untuk URL yang betul.

🔄 Aliran Kerja Sistem

# Tindakan Modul Siapa
1 Daftar audit baharu (tajuk, jabatan, tarikh, skop) 📅 Jadual Audit Juruaudit
2 Isi borang semakan PK — pilih Audit ID → pilih PK → isi wizard 5 langkah 📋 Borang Semakan PK Juruaudit
3 Item bertanda "Tiada" → auto-muncul sebagai alert dalam dashboard 📊 Dashboard KPI PK
4 Daftar Findings/NCR berdasarkan item Tiada 🔍 Findings / NCR Juruaudit
5 Buka Tindakan Pembetulan (CAR) untuk setiap NCR ✅ CAR Juruaudit
6 Pantau progress, semak KPI dan export laporan Excel 📤 Export PKPengarah
